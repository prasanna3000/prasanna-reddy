# Portfolio website

This is a dependency-free static portfolio, suitable for GitHub Pages.

Before publishing, replace these placeholders in `index.html`:

- Any project-specific GitHub links you want to add later

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, go to **Settings → Pages** and set **Source** to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Add your custom GoDaddy domain in the same Pages settings. GitHub will show the DNS records to add in GoDaddy.
5. In GoDaddy DNS, usually add a `CNAME` record for `www` pointing to `YOUR-GITHUB-USERNAME.github.io`. For the root domain, use GitHub's current A records shown in the Pages setup page.

GitHub Pages will automatically enable HTTPS after DNS is set up.
